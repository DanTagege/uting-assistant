# 上游接口说明

本文档记录本项目对接 **U校园（U听说 / U听力）** 所使用的接口约定，供维护者参考。
所有路径均以线上实际行为为准；接口可能变化，改版时请以新的抓包结果更新本文。

## 主机

| 主机 | 用途 |
|---|---|
| `sso.unipus.cn` | 统一登录、令牌续期 |
| `ucloud.unipus.cn` | 周进度、历史记录（App 口径） |
| `uadaptive.unipus.cn` | 取卷、作答、交卷、判分、定级报告 |

## 接口

| 用途 | 方法 & 路径 | 备注 |
|---|---|---|
| 账号密码登录 | `POST /sso/0.1/sso/cip/login` | 请求体字段经 AES-128-CBC 加密，密钥/IV 随前端下发 |
| 令牌续期 | `POST /sso/4.0/sso/refresh_jwt` | 用 refresh token 换新 JWT |
| 周进度（App） | `GET /api/uls/user/getUserStatusForApp?flowType=listen` | 需 `u-app-id: 116`；返回本周完成数/总数、当前级别 |
| 当前任务 | `GET /api/uls/user/getUserStatus?flowType=listen` | `type` 为 `grade` / `train_plan` / `train` |
| 取卷 | `POST /api/uls/user/loadPaper` | 入参 `taskId`、`ansVersion`；返回 `paperJson` 与 `token` |
| 作答快照 | `POST /api/uls/user/saveSnapshot` | 作答中途保存，不影响最终判分 |
| 交卷 | `POST /api/uls/user/submitAnswer` | 必须带 `loadPaper` 返回的 `token` 与全量 `userData` |
| 读分 | `POST /api/uls/user/loadGradedQuestions` | 逐题得分与总分 |
| 训练历史 | `POST /api/uls/user/getHistoryTrainingTasks` | 分页 |
| 定级报告 | `POST /api/uls/report/levelReport` | 返回 `level` / `levelName` / 描述 |

## 通用约定

- `Authorization` 直接放 **JWT 原文**，不加 `Bearer` 前缀
- 业务成功码在不同接口可能是 `0` / `1` / `200`，需按接口判断
- 时间相关字段为秒级时间戳
- 并发约束：同一篇卷不要多端同时作答，否则返回 `4021`

## 试卷结构

```
paperJson.chr[]                      ← 章（lead-in / pre-listening / while / post-listening）
  └ chr[]                            ← 题目单元
      ├ q_qinstid      19 位雪花 id（JSON 数字，需按字符串处理）
      ├ q_idx          题号
      ├ nm             题型名称（听力_单选_客观题 / 单词跟读 / 音频学习 …）
      ├ q_template_name single-choice_objective / vocabulary / sequence_objective / outline
      ├ is_objective   是否客观题
      └ data
          ├ children[] 子题（一题多问、排序题的每个位置）
          ├ options[]  选项，text 字段带 HTML 实体
          ├ contents[] 原文/字幕与音频路径
          └ replyType  singlechoice / outline / sequence
```

**排序题**：选项中 `value` 字段表示该项的正确位置（如 `{name:"A", value:"4"}` 表示 A 为第 4 步），
因此正确顺序可由 `value` 直接还原，无需模型参与。

## 提交格式

```jsonc
{
  "taskId": "...",
  "ansVersion": 1,
  "token": "<loadPaper 返回的 token>",
  "duration": 723,                  // 秒；与真实作答时长一致
  "userData": [
    {
      "instanceId": "1989...",
      // 注意：answer / context 都是「JSON 字符串」，不是对象
      "answer": "{\"value\":[],\"children\":[{\"value\":[\"C\"]},{\"value\":[\"B\"]}]}",
      "answerVersion": 1,
      "context": "{\"state\":\"done\"}",
      "contextVersion": 1
    }
  ]
}
```

- `children` 段数必须与该实例的子题数一致；全卷上报的 `children` 总数必须等于卷面叶子数
- 口语类题（跟读）不参与客观题提交，跳过即可

## 业务错误码

| code | 含义 | 处理建议 |
|---|---|---|
| `0` / `1` / `200` | 成功（按接口区分） | — |
| `1506` | 登录需要滑块验证 | 浏览器完成登录后导入 JWT |
| `4012` | 账号尚未定级 | 先完成定级 |
| `4013` | 该训练已提交 | 跳过，不要重复交卷 |
| `4021` | 多端同时作答 / token 冲突 | 关闭另一端后重新取卷 |
| `4295` | 上报小题数与卷面不符 | 检查 `children` 数量与结构 |
